# Student Management System (C++)

A console-based Student Management System implemented in C++.
It supports CRUD operations with GPA and CGPA calculations.

## Features
- Add new student records
- Display all students
- Search by roll number
- Update student details
- Delete single or all records
- Semester-wise GPA & CGPA calculation

## How to Compile and Run

### Using g++
```bash
g++ main.cpp -o student_system
./student_system
